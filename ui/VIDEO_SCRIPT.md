# 离线演示备用取景脚本

用途：复现本地离线演示并准备备用录屏。下表为约 3 分 28 秒的取景草案；正式投稿使用已发布的 160 秒英文成片，链接见 [README](../README.md)。真实 Nebius/NVIDIA 模型协同使用独立模型入口，本脚本的 UI 展示本地计算路线。

**录制要求：画面与字幕中的数字对应当次运行回执，使用与回执关联的素材。
片尾标明版本 commit 和 `run_id`，完整运行目录保留在私有回执中。
录屏隐藏本机用户名、凭据和私有路径，保留可供核对的版本与记录身份。**

---

## 0. 录制前 5 分钟检查

```powershell
Set-Location C:\h56demo         # 替换为按恢复指南得到的实际克隆或解压目录
git status --porcelain          # Git 克隆必须为空；ZIP 无 .git，改用恢复指南的清单摘要校验
python -B -c "import sys;print(sys.version)"
python -B demo.py               # 主线 6 案例，约 5 秒，确认 6/6 与 6 条输入互不相同
python -B -m ui.test_release_guards               # 12 项发布守卫
```

默认主线为 6 项性质 PASS、跨解释器项 SKIP。录制跨解释器对照时，先配置第二解释器路径，再运行文末的可选命令；7 项 PASS 按实际跨解释器回执呈现。

> 应用命令使用 `-B` 保持仓库文件成员稳定。默认允许写字节码的环境可能生成 `__pycache__`；
> `verify_pack.py` 将这些清单外文件报告为 `EXTRA_FILE`。

- 分辨率 1920×1080，浏览器缩放 100%，关掉所有通知。
- 终端字号调到 16–18pt，背景纯黑，不要半透明。
- 先全流程彩排计时，再正式录。主线约 5 秒、全量约 45 秒，原始素材保留完整启动与结果过程；
  剪辑压缩等待时标明时间处理方式，另保留未经剪辑的原始片段。

## 2. 现场说明要点

- **输入拒绝**：逐条查看停止阶段、原因码和产物列表；校验拒绝与四核计算结局分别显示。
- **回归覆盖**：56 行覆盖 26 条不同输入，基准信封出现 31 次，其余 25 条输入各出现一次。
  30 行重复用于基线比对，按不同输入统计的 FEASIBLE 为 2 条。
- **模型协同**：本页的结构化输入由合成 fixture 构造。独立的 Nebius/NVIDIA 路线由模型提出
  已登记场景，Adapter 校验并映射到对应输入，再由原版四核计算资格。模型提案与可信事实、
  核心计算采用明确分工。
- **跨解释器**：性质 3 对照 C01 的语义摘要。已有版本对为 3.9.13 与 3.13.12；现场展示实际
  解释器版本和该用例回执。
- **执行权限**：本演示输出候选资格与规划层记录，`authority_granted`、`execution_permitted`
  为 false，`business_action_calls` 为 0。资格计算与执行授权分别处理。
- **验证配置**：展示对应入口、运行环境和回执。完整操作与证据字段见演示指南和恢复指南。
